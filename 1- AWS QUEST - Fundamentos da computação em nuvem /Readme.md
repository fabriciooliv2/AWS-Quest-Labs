# Hospedagem de Sites Estáticos no Amazon S3

## Descrição

Neste laboratório foi realizada a migração de um site para hospedagem estática utilizando o Amazon S3.

## Objetivos

- Criar bucket S3
- Configurar hospedagem estática
- Permitir acesso público ao conteúdo
- Publicar o site

## Serviços Utilizados

- Amazon S3

## Passos Executados

1. Criação do bucket S3
2. Upload dos arquivos do site
3. Renomeação do arquivo principal para waves.html
4. Desativação do Block Public Access
5. Aplicação da política de bucket
6. Testes de acesso
