# ☁️ AWS Quest Lab 02 - Primeiros Passos na Nuvem

## 📋 Descrição

Neste laboratório do **AWS Cloud Quest**, realizei a criação de recursos essenciais da AWS para compreender os fundamentos da computação em nuvem.

Durante a atividade foram explorados serviços de armazenamento, computação, rede e segurança, culminando na publicação de uma aplicação web em uma instância EC2.

---

## 🎯 Objetivos do Laboratório

✅ Navegar pelo Console AWS

✅ Criar e configurar um Bucket S3

✅ Realizar upload de objetos

✅ Provisionar uma instância Amazon EC2

✅ Configurar armazenamento EBS

✅ Aplicar regras de segurança utilizando Security Groups

✅ Publicar uma página web simples

---

## 🛠️ Serviços AWS Utilizados

| Serviço | Descrição |
|----------|------------|
| 🪣 Amazon S3 | Armazenamento de objetos |
| 💻 Amazon EC2 | Hospedagem da aplicação |
| 💾 Amazon EBS | Armazenamento persistente |
| 🌐 Amazon VPC | Rede virtual |
| 🔒 Security Groups | Controle de acesso |
| 📊 AWS Console | Gerenciamento dos serviços |
